# AI 味体检

免费网文 AI 味检测器：粘贴正文 → 0-100 评分 + 逐处定位 + 去味改写 Prompt。

**纯前端，零依赖，数据不出浏览器。**

## 在线使用

https://31415959.github.io/deai-web/

## 本地使用

下载 index.html / detector.js / data.js 三个文件放同一目录，双击 index.html。

## 它检测什么

| 层 | 类别 | 手段 |
|---|---|---|
| 词库 | 连接词 / AI 高频词 / 程度副词 / 名词化 / 情绪直述 / 套话 / 抽象空词 | 7 类 214 词条 |
| 结构 | 金句升华模板 / 抽象主语 / 排比三件套 | 句级正则 + 前缀指纹 |
| 统计 | 句长·段落变异系数、破折号·省略号密度、超长无标点片段 | 纯统计 |

## 区分度实测

| 文本 | 分数 |
|---|---|
| AI 生成样本 | 41.4 |
| 真人网文（4 个对照组） | 0.8 / 1.5 / 8 / 10.4 |
| 手写干净白话 | 0 |

AI 样本是真人最高分的 4.0 倍。

## 说明

检测器只报数据、逐句定位，**不下「是不是 AI 写的」结论**。评分是「AI 味浓度」参考，不是鉴定。改写交给 AI 执行，保证不误伤剧情人设。
