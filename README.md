## 它检测什么

| 层 | 类别 | 手段 |
|---|---|---|
| 词库 | 连接词 / AI 高频词 / 程度副词 / 名词化 / 情绪直述 / 套话 / 抽象空词 | 7 类 214 词条 |
| 结构 | 金句升华模板 / 抽象主语 / 排比三件套 | 句级正则 + 前缀指纹 |
| 统计 | 句长·段落变异系数、破折号·省略号密度、超长无标点片段 | 纯统计 |

判读阈值会按文本长度自适应（`sqrt(字数/2000)`）：短文本命中天然少，
固定阈值会系统性漏判。**分数本身不缩放**，只缩放判读档位。

## 适用与不适用

- ✅ **中文网文**（都市、玄幻、悬疑等叙事文体）
- ❌ **新闻 / 影评 / 论文** —— 词表是针对网文调的。
  实测各域误报率：作文 2.5%、新闻 10.0%、**影评 43.8%**、问答 15.0%、论文 12.5%。
  这些文体请勿采信本工具结果。

## 它不下结论

检测器只报数据、逐句定位，**不判断「是不是 AI 写的」**。
评分是「AI 味浓度」参考，不是鉴定。改写交给 AI 执行，保证不误伤剧情人设。
